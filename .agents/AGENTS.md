This project utilizes two specialized subagents:

## 1. `mobile_ui_developer`
- **Role**: React Native & Expo UI/UX Specialist
- **Responsibilities**:
  - Building screens ([src/screens](file:///home/ahmet/Projects/fitness-tracker/src/screens)) and reusable components ([src/components](file:///home/ahmet/Projects/fitness-tracker/src/components))

## 2. `health_data_engineer`
- **Role**: Health Data, Services & Storage Specialist
- **Responsibilities**:
  - Managing `react-native-health-connect` integrations
  - Handling `AsyncStorage` and data persistence ([src/services](file:///home/ahmet/Projects/fitness-tracker/src/services))
  - Setting up `expo-notifications` for workout tracking & step counting goals
  - Defining TypeScript data models and analytics ([src/types](file:///home/ahmet/Projects/fitness-tracker/src/types))
